# 📝 Student Files

This folder contains one Markdown file per student. When your PR is merged,
your file gets parsed and your card appears on the **Class Wall**!

---

## How to create your file

1. Create a new file in this folder named **`<your-github-username>.md`**
   (for example: `octocat.md`).

2. Copy the template below and fill in your details:

```markdown
---
name: Your Full Name
github: your-github-username
bio: A one-line bio about yourself
favourite: Your favourite programming language or tool
---

## 👋 Hello!

Write a sentence or two about yourself here. This part is optional but
encouraged!
```

3. Make sure you fill in **all four** front-matter fields (`name`, `github`,
   `bio`, `favourite`) — the CI check will fail if any are missing.

---

## Rules

- **One file per student.**
- **Filename = your GitHub username** (e.g. `octocat.md`, not `my-file.md`).
- Do not edit or delete anyone else's file.
- Keep it friendly and appropriate.
